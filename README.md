# NOCTURNA — sitio web minimalista

Este proyecto es un sitio web estático (HTML/CSS) para la marca de ropa streetwear **NOCTURNA**.

## Cómo verlo localmente

> Puedes abrir `index.html` directamente en el navegador, o levantar un servidor estático para
> que funcionen bien los enlaces internos.

### Opción rápida (sin servidor)

1. Abre el archivo `index.html` en tu navegador.

### Opción recomendada (con servidor)

```bash
python -m http.server 8000
```

Luego visita: `http://localhost:8000/index.html`

## Páginas incluidas

- `index.html` — landing principal.
- `drops.html` — página de drops exclusivos.
- `bestsellers.html` — página de bestsellers.
